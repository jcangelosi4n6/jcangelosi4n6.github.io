## What Prefetch tells you

Windows Prefetch files (`C:\Windows\Prefetch\*.pf`) are evidence of **program execution**. Each file records:

| Field | Why it matters |
|---|---|
| Executable name + path hash | Which binary ran, and from where |
| Run count | How many times it ran |
| Last run times (up to 8 on Win8+) | When it ran |
| Files/directories referenced | What it touched in its first ~10 seconds |

> Prefetch is disabled by default on many Windows Server builds, and on some systems with SSDs.
> Absence of a `.pf` file is not proof a program never ran.

## Parsing them

Eric Zimmerman's `PECmd` makes quick work of a whole directory:

```powershell
PECmd.exe -d "E:\Triage\C\Windows\Prefetch" --csv "E:\Out" --csvf prefetch.csv
```

Or with Python, if you want to script a quick sweep for suspicious names:

```python
from pathlib import Path

SUSPICIOUS = {"PSEXEC", "MIMIKATZ", "PROCDUMP", "RCLONE"}

for pf in Path("Prefetch").glob("*.pf"):
    name = pf.stem.rsplit("-", 1)[0]
    if name.split(".")[0] in SUSPICIOUS:
        print(f"[!] {pf.name}")
```
